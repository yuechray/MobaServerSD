## 1. Обзор архитектуры

Игра использует **SpacetimeDB** — облачная база данных с серверной логикой на C#, скомпилированной в WebAssembly. Все игровые вычисления (движение, урон, спавн, победа) происходят на сервере. Клиент (Unity) только отправляет команды игрока и отображает обновления таблиц.

```
┌──────────────────────────────────────────────────────────┐
│                      Unity Client                        │
│                                                          │
│  LoginManager → LobbyManager → SpacetimeNetworkManager  │
│                                    ↑ EntityFactory       │
│                                    ↑↓ WebSocket          │
│  ChampionController  CreepController  StructureController│
│  ChampionInputHandler ChampionAnimator                   │
└──────────────────────────────────────────────────────────┘
                           ↕
┌──────────────────────────────────────────────────────────┐
│             SpacetimeDB (maincloud.spacetimedb.com)      │
│                                                          │
│  Config · GameState · UserProfile · LobbyPlayer          │
│  Champion · Structure · Creep                            │
│  GameTickSchedule · CreepSpawnSchedule                   │
│                                                          │
│  GameTick @ 20 Hz — движение, атаки, смерть, возрождение │
│  SpawnCreepWave @ 30 сек — волны крипов на линиях        │
└──────────────────────────────────────────────────────────┘
```

**Сервер авторитарен** — клиент не может изменить позицию или здоровье напрямую.

### 3.2 Редьюсеры

#### `RegisterProfile(string username)`
Регистрирует или обновляет аккаунт. Вызывается один раз при первом входе.
- Имя уникально среди всех пользователей
- Если аккаунт уже существует — обновляет имя

```csharp
conn.Reducers.RegisterProfile("Иван");
```

---

#### `JoinLobby(string name)`
Входит в текущее лобби. Вызывается автоматически после регистрации/входа.
- Создаёт строку в `LobbyPlayer`
- Если игрок уже в лобби — обновляет запись (идемпотентен)
- Выбрасывает ошибку если матч уже идёт

```csharp
conn.Reducers.JoinLobby("Иван");
```

---

#### `SelectTeam(Team team)`
Выбирает команду. Работает только в фазе `Lobby`.
- Сбрасывает готовность (`IsReady = false`)
- Не принимает `Team.None`

```csharp
conn.Reducers.SelectTeam(Team.Radiant);
```

---

#### `SetReady(bool ready)`
Устанавливает/снимает готовность. Если все подключённые игроки (≥2) готовы — запускает матч:
- `GameState.Phase` → `InGame`
- Спавнит чемпионов, структуры, нейтральных крипов

```csharp
conn.Reducers.SetReady(true);
```

---

#### `MoveToPosition(float x, float y, float z)`
Отдаёт команду движения. Сбрасывает цель атаки. Игнорируется если персонаж мёртв.

```csharp
conn.Reducers.MoveToPosition(hit.point.x, hit.point.y, hit.point.z);
```

---

#### `IssueAttack(TargetKind targetKind, ulong targetId)`
Атакует указанную цель. Поддерживает все три типа: чемпионы, крипы, структуры.
- Нельзя атаковать союзников
- Игнорируется если цель или атакующий мёртвы/уничтожены

```csharp
conn.Reducers.IssueAttack(TargetKind.Champion,   enemyChampionId);
conn.Reducers.IssueAttack(TargetKind.Creep,      creepId);
conn.Reducers.IssueAttack(TargetKind.Structure,  towerOrThroneId);
```

---

#### `ResetMatch()`
Сбрасывает матч — удаляет всех чемпионов, структуры, крипов и игроков лобби. Возвращает в фазу `Lobby`.

---

#### `SpawnCreepWave()` (scheduled, каждые 30 сек)
Автоматически спавнит по 3 меле-крипа на каждой линии за каждую команду (18 крипов на волну).

---

### 3.3 Игровой цикл

`GameTick` вызывается **20 раз в секунду** (каждые 50 мс). Работает только в фазе `InGame`.

**Порядок обновлений за один тик:**
1. Все чемпионы → `TickChampion`
2. Все структуры → `TickStructure`
3. Все крипы → `TickCreep`
4. Проверка победы

**Логика тика чемпиона:**
```
Dead?
  → прошло RespawnDuration? → возродить на точке спавна команды

Attacking?
  → цель мертва/уничтожена? → перейти в Idle
  → цель слишком далеко? → двигаться к цели (StepTowards)
  → в радиусе + прошёл AttackCooldown? → нанести урон

Moving?
  → дошли до Destination (< 0.5 ед.)? → State = Idle
  → иначе → StepTowards(Destination)
```

**Логика тика башни:**
- Приоритет целей: вражеские чемпионы > крипы волн
- Атакует автоматически в радиусе `TowerAttackRange`
- Трон не атакует

**Логика тика крипа волны:**
- Движется по вейпоинтам линии (5 точек на линию)
- Агрится на врагов в радиусе `AttackRange * 2.5`
- После смерти: удаляется через 5 секунд

**Логика тика нейтрала:**
- Стоит на месте, агрится на подошедших врагов
- После смерти: возрождается через `NeutralRespawnSec` (60 сек) если лагерь пуст

**Победа:** наступает мгновенно при уничтожении трона — `GameState.Phase = GameOver`, `WinnerTeam = атакующая команда`.

## 4. Unity — скрипты

### 4.1 Иерархия контроллеров

```
EntityController  (abstract)
│  EntityId, IsInitialized
│  SetHPBar(), HideHPBar(), BillboardHPBar()
│  ToVector3() static helper
│
├── MobController  (abstract)  ← движущиеся сущности с NavMeshAgent
│   │  Agent (NavMeshAgent)
│   │  SyncPosition(), SetNavDestination(), StopNav()
│   │
│   ├── ChampionController     ← синхронизация состояния чемпиона
│   └── CreepController        ← синхронизация крипа + HP bar
│
└── StructureController        ← синхронизация структуры + HP bar
```

Все контроллеры инициализируются методом `Init(ulong id)`. Для чемпиона: `Init(ulong id, bool isLocal)`.

### 4.2 Сетевые скрипты

#### `SpacetimeNetworkManager`
Синглтон (`DontDestroyOnLoad`). Управляет подключением и синхронизацией.

- Подключается к `wss://maincloud.spacetimedb.com`, модуль `moba-server`
- Читает токен из аргумента `-stdb-token` при запуске
- Вызывает `conn.FrameTick()` в `Update()`
- Подписывается на Insert/Update/Delete для Champion, Structure, Creep, GameState
- При `GameState.Phase = InGame` → загружает сцену Game
- Требует компонент `EntityFactory` на том же объекте

**Публичные свойства:**
```csharp
DbConnection Conn             // прямой доступ к соединению
bool IsSubscriptionApplied    // подписка применена
bool IsConnected              // активное соединение
event Action OnSubscriptionApplied

ChampionController GetLocalChampion()  // контроллер своего чемпиона
```

---

#### `EntityFactory`
Компонент на том же GameObject, что и `SpacetimeNetworkManager`. Отвечает за создание всех игровых объектов.

**Поля в Inspector:**

| Поле | Описание |
|------|----------|
| Local Champion Prefab | Префаб своего чемпиона |
| Remote Champion Prefab | Префаб чужого чемпиона |
| Radiant/Dire Tower Prefab | Префабы башен |
| Radiant/Dire Throne Prefab | Префабы тронов |
| Radiant/Dire/Neutral Creep Prefab | Префабы крипов |

Если префаб не назначен — используется fallback (капсула/куб с цветом команды).

---

#### `ChampionController`
Синхронизирует позицию и состояние чемпиона с сервером.

**Для своего чемпиона (`IsLocalPlayer = true`):**
- Варп к серверной позиции если дрейф > 1.5 ед.
- Устанавливает NavMesh destination по серверному `Destination`

**Для чужого (`IsLocalPlayer = false`):**
- `Lerp` к серверной позиции (скорость 12)
- NavMesh следует серверному Destination

> **Ввод** и **анимации** вынесены в отдельные компоненты.

---

#### `ChampionInputHandler`
Отдельный MonoBehaviour. Обрабатывает правый клик:
- Клик по вражескому чемпиону → `IssueAttack(TargetKind.Champion, id)`
- Клик по крипу → `IssueAttack(TargetKind.Creep, id)`
- Клик по структуре → `IssueAttack(TargetKind.Structure, id)`
- Клик по земле → `MoveToPosition(x, y, z)`

Активен только на своём чемпионе (`IsLocalPlayer = true`). Должен быть на том же GameObject, что и `ChampionController`.

---

#### `ChampionAnimator`
Отдельный MonoBehaviour. Управляет Animator и dissolve-эффектом.

**Анимации (имена в Animator Controller):**

| Состояние | Хэш |
|-----------|-----|
| Стоит | `Base Layer.idle` |
| Идёт | `Base Layer.move` |
| Атакует | `Base Layer.attack_shift` (тег: Attack) |
| Умирает | `Base Layer.dissolve` |

Dissolve: скорость 0.8/сек, свойство `_Dissolve` на SkinnedMeshRenderer (float, 1 = живой, 0 = исчез).

---

#### `CreepController`
Синхронизация крипа: позиция (Lerp × 10), NavMesh, анимации (Move/Attack/Dead bool), HP bar billboard.

#### `StructureController`
Синхронизация структуры: HP bar, при уничтожении — серый цвет рендереров.

## 5. Unity — настройка сцен

### Сцена Login

```
Login (Scene)
├── NetworkManager    ← SpacetimeNetworkManager + EntityFactory (компоненты)
├── UIDocument        ← LoginManager + ссылка на UXML
└── EventSystem
```

---

### Сцена Lobby

```
Lobby (Scene)
├── NetworkManager    ← тот же DontDestroyOnLoad (или пустышка)
├── UIDocument        ← LobbyManager + ссылка на UXML
└── EventSystem
```

---

### Сцена Game

```
Game (Scene)
├── NetworkManager    ← тот же DontDestroyOnLoad (или копия с префабами для Game-сцены)
├── Terrain           ← должен охватывать 0–512 на X и Z
├── NavMesh           ← запечён по поверхности терейна
├── Camera            ← MobaCamera (или DOTAEdgeCamera)
│   └── (следит за GetLocalChampion())
└── UIDocument        ← GameUIManager + ссылка на UXML
```

**Важно:** Если `SpacetimeNetworkManager` существует из прошлой сцены — он копирует префабы из нового объекта перед самоуничтожением. Это позволяет назначать разные префабы в каждой сцене.

**NavMesh:** запеки по всему терейну. Чемпионы и крипы требуют `NavMeshAgent`. Префабы со встроенным агентом не требуют дополнительной настройки — Factory добавит его автоматически при необходимости.

## 6. Поток игры (Game Flow)

```
[Запуск Unity]
      │
      ▼
[Сцена Login]
 SpacetimeNetworkManager подключается к maincloud
      │
      ▼
[Подписка применена] → OnSubscriptionApplied
      │
      ├─ UserProfile существует?
      │      ДА → Welcome-панель → кнопка "Войти в лобби"
      │      НЕТ → Register-панель
      │                │
      │                ▼
      │      RegisterProfile("username")
      │      → профиль создан → LoadScene("Lobby")
      │
      ▼
[Сцена Lobby]
 LobbyManager.AutoJoin() → JoinLobby(username)
      │
      ▼
[Игрок выбирает команду]
 SelectTeam(Team.Radiant | Team.Dire)
      │
      ▼
[Игрок нажимает READY]
 SetReady(true)
 Сервер: все ≥2, у всех команды, все готовы
   → GameState.Phase = InGame
   → SpawnAllChampions + SpawnAllStructures + SpawnNeutralCreeps
      │
      ▼
[SpacetimeNetworkManager: GameState.Phase = InGame]
 → LoadScene("Game")
      │
      ▼
[Сцена Game загружается]
 EntityFactory.SpawnChampion / SpawnStructure / SpawnCreep
      │
      ▼
[Игра идёт]
 Правый клик по земле → MoveToPosition
 Правый клик по врагу / крипу / башне → IssueAttack
 Сервер: 20 тиков/сек — движение, урон, смерть, возрождение
 Сервер: каждые 30 сек → SpawnCreepWave (18 крипов)
      │
      ▼
[Трон уничтожен]
 GameState.Phase = GameOver, WinnerTeam = атакующая команда
 GameUIManager показывает "ПОБЕДА!" или "ПОРАЖЕНИЕ"
      │
      ▼
[Кнопка Exit / ResetMatch]
 Возврат в Lobby или выход
```

## 7. Как пересобрать и задеплоить сервер

```bash
# Сборка (проверка ошибок)
cd C:\Users\den74\MOBAServer\server
dotnet build

# Публикация (УДАЛЯЕТ все данные!)
spacetime publish moba-server --clear-database -y --project-path C:\Users\den74\MOBAServer\server
```

> **Внимание:** `--clear-database` удаляет всех пользователей, матчи, конфиг. Нужен только при изменении структуры таблиц. Для обновления логики без изменения схемы можно публиковать без этого флага.

**Просмотр логов сервера:**
```bash
spacetime logs moba-server
```

## 8. Как обновить клиентские биндинги

После изменения таблиц или редьюсеров в серверном коде:

```bash
# Генерация биндингов для Unity
spacetime generate --lang csharp ^
  --out-dir "C:\Users\den74\MOBA\Moba 1.000\Assets\SpacetimeDB" ^
  --project-path C:\Users\den74\MOBAServer\server
```

> Биндинги находятся в `Assets/SpacetimeDB/` — **никогда не редактируй** эти файлы вручную.

После генерации Unity автоматически перекомпилирует скрипты.

## 9. Часто встречаемые ошибки

### Ошибки сборки сервера

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `BSATN0001` | Enum без `[SpacetimeDB.Type]` | Добавь атрибут к каждому enum |
| `BSATN0002` | Enum с явными значениями или `: byte` | Убери `= 0, = 1` и `: byte` |
| `STDB0010` | Reducer начинается с "On" | Переименуй: `OnConnect` → `ClientConnected` |
| `STDBINT0001` | Дубликаты типов при компиляции | Убедись что `Lib.cs` удалён, нет задвоений в `src/` |
| `CS1955` | `ScheduleAt.Interval` как метод | Используй `new ScheduleAt.Interval(...)` |
| `CS1061` | `MicrosecondsSinceEpoch` не найден | Правильно: `MicrosecondsSinceUnixEpoch` |
| Table is `class` | Таблица `partial class` | Должно быть `partial struct` |
| wasi-experimental not found | Используется .NET 9 | Нужен .NET 8 + `global.json` |

### Ошибки в Unity

| Проблема | Причина | Решение |
|----------|---------|---------|
| Сущности не спавнятся | Префабы не назначены | Назначь префабы в `EntityFactory` в Inspector |
| `EntityFactory` не найден | Компонент не добавлен | Добавь `EntityFactory` на тот же объект, что и `SpacetimeNetworkManager` |
| Анимация не работает | Названия состояний не совпадают | Проверь: `Base Layer.idle`, `Base Layer.move`, `Base Layer.attack_shift`, `Base Layer.dissolve` |
| Dissolve не работает | Нет свойства `_Dissolve` | Добавь Float-свойство `_Dissolve` в шейдер материала |
| HP bar не виден | Canvas не назначен | Назначь `hpCanvas` и `hpFill` в Inspector контроллера |
| Сцена не переключается | Сцена не в Build Settings | File → Build Settings → Add Open Scenes |
| `NullReferenceException` на `Conn` | SDK ещё не загрузился | Подожди `OnSubscriptionApplied` |

### Ошибки соединения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Connection error | Неверный URI или имя модуля | Проверь `serverUri = wss://maincloud.spacetimedb.com` и `moduleName = moba-server` |
| "Username already taken" | Имя занято | Выбери другое имя |
| "Call JoinLobby first" | Редьюсер вызван без входа в лобби | `JoinLobby` должен вызываться автоматически через `LobbyManager.AutoJoin()` |
| "Match already in progress" | `JoinLobby` вызван во время игры | Нормальное поведение — перезапусти лаунчер после окончания матча |
| "Select a team before readying up" | `SetReady(true)` без команды | Сначала нажми Radiant или Dire |
| "Cannot attack ally" | Клик по союзнику | Ожидаемое поведение — атаковать можно только врагов |
